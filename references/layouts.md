# 三种布局

这三张图是布局和视觉层级的参考，**不是内容模板**。每次换成用户自己的产品截图、IP 和标题。不要沿用参考图中的功能名称、品牌或人物。

## A：上方标题，下方大屏幕

参考 [layout-a.png](../assets/layout-a.png)。顶部约三分之一是完整的深色标题区，主问题一眼可读；下方明亮的大屏幕向右侧越出画幅。电脑有轻微斜向透视：屏幕上沿略倾斜，能看见边框厚度和底座，不能做成正面居中、四边完整露出的平板矩形。IP 小人从左下前景参与观看，与屏幕底缘或桌面有自然遮挡、接触阴影和屏幕反光；不能只是角落里的头像贴纸。横向界面需要更多可见宽度时默认选它。标题可以是“对象/场景＋具体问题”，把问题或数字放大。

## B：左侧标题，右侧大屏幕

参考 [layout-b.png](../assets/layout-b.png)。左侧约四成宽度承载分行标题；右侧大屏幕以斜向透视延伸出画面，不能缩成一块小型平板。IP 从标题和屏幕的分界处指向具体功能，身体与电脑边缘产生前后遮挡和接触阴影。只有屏幕自然裁成右侧窄幅后，关键功能仍能辨认，而且指向动作确实帮助观看时才选它。标题应比参考图更精炼时就精炼，留出角色呼吸空间。

## C：屏幕特写，具体问题

参考 [layout-c.png](../assets/layout-c.png)。只放大与本期问题相关的一两个界面区域，标题在上方或左上深色空区，IP 从下方边缘探入并指向目标，保留与屏幕之间的遮挡和光影。需要局部细节时选它；不要把无关的整页 UI 塞进画面。

## 三种布局共用的判断

- 缩成手机列表尺寸时，第一眼读到的是标题里的具体信息，而不是亮屏或人物。标题用参考图那样厚实、现代的无衬线黑体，字重和字号形成明确主次；白字为主，只给关键词或数字加少量克制蓝色。避免宋体、书法体、手写体、细字和整行蓝字。没有提供原字体文件时追求字形观感，不声称能复刻字体名称。
- 屏幕需要像视频中的真实电脑界面；保留原图的真实内容，裁掉 Logo 所在区域。
- IP 有辨识度，动作服务于本期界面；保持为画面配角。
- 背景和道具保持安静。深海军蓝到炭灰的平滑底色、单一柔和光源和轻微屏幕光已足够；桌面可以隐约存在以承接电脑和人物，不要加植物、书本、台灯、霓虹灯带、密集键鼠等无关物件。
